2. COMPILATION INSTRUCTIONS FOR WINDOWS (BUILDER MACHINE)
--------------------------------------------------------------------------------
To compile on any Windows 10/11 system:
1. Open Command Prompt in the project folder.
2. Run:
     scripts\build_exe.bat

This invokes:
  Step A: Native C DLL Compilation
    gcc -shared -O3 -Wall -Wextra -DBUILDING_MATH_ENGINE c_engine\math_engine.c -o release\math_engine.dll
    (or cl /LD /O2 /DBUILDING_MATH_ENGINE c_engine\math_engine.c /Fe:release\math_engine.dll if using MSVC)

  Step B: PyInstaller Standalone Packaging
    pyinstaller --noconfirm --clean nexus_math.spec

Output is created at:
  release\dist\NEXUS_MATH\NEXUS_MATH.exe
